# VLA-MAVSDK
MAVSDK enabled UAV controlled by VLA

Under Construction

1. Objective 
- Create a Vision based action model for UAS with MAVSDK taking the role of Brain.
- Vision Model will analyse and determine the objective of the mission through text input, after the input is taken into consideration the VLA model makes the plan of action and shares the plan with MAVSDK to where to move and what is the distance and other all relevant information.
- The MAVSDK shares the information with Flight controller or any Controllers. (We are using MAVSDK since the environment already existing it is easy to integrate as well as light weight architecture).
  
2. Planning
- First stage will be developing the VLA model for the purpose of UAVs, input from the camera and other sensors, plan the action.
- Second stage will involving sharing the action with the flight controller directly or through MAVSDK
- simulation & Ground test of the architecture
- Field test
- Making the architecture hardware agnostic.
